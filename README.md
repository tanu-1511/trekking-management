# Trekking Management Application

A role-based Trekking Management web application built using Flask, SQLite, Jinja2, and Bootstrap.

## Features

- Admin Dashboard
- Staff Management
- Trek Booking
- Trek Assignment
- Authentication
- Booking History

## Tech Stack

- Python
- Flask
- SQLite
- SQLAlchemy
- Flask-Login
- Flask-WTF
- Bootstrap
